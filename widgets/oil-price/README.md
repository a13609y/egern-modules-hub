# 全国实时油价 · Egern 小组件模块

92 / 95 / 98 号汽油与 0 号柴油实时油价 + **真实官方调价历史走势**，三套尺寸布局，深浅色自适应。

- 现价源：<http://m.qiyoujiage.com>（省份/城市页面解析；站点改版可能失效，失败回退上次缓存）
- 历史源：**BesFuel** 已逐期核实的发改委调价历史（元/升真实节点，见下文「历史从哪来」）
- 支持尺寸：小号 `systemSmall`、中号 `systemMedium`、大号 `systemLarge`（锁屏 accessory 尺寸只显示单价）
- 组件名：**实时油价**

## 安装

1. Egern → 工具 → 模块 → `+` → 粘贴模块地址：

```
https://raw.githubusercontent.com/a13609y/egern-modules-hub/main/widgets/oil-price/oil-price.yaml
```

2. 保存后点开该模块，在「参数」里填地区（默认 `hainan/haikou`）。
3. 回主屏幕长按 → `+` → Egern → 选尺寸 → 长按组件 → 编辑小组件 → 选择「实时油价」。

### 图表怎么画（v4.4.0）

- **最多最近 10 轮**：只渲染序列最后 10 个**真实历史节点**（`slice(-10)`），节点日期/价格原样取自 BesFuel，不补点、不插值、不伪造「第 N 轮」。
- **普通直线连接**：相邻真实节点之间是直线段；直线只表示两次真实调价之间的价差趋势，**不是逐日价格**，也不代表任何中间值。
- **浅橙渐变面积**：折线到基线之间用 `linearGradient` 橙色 0.34→0.02 的半透明面积做视觉强调。
- **节点与末点**：普通调价为橙色实心圆点，官方「不作调整」为空心圆点；最新一个节点用**绿色大圆**强调，**不写末点价格标签**（参考图无价签，也避免遮挡折线与坐标文字）。
- **缺口不连**：`historyGaps` 命中的位置把折线与面积都断开成多段，不跨缺口连线。
- **坐标轴**：X 轴首/中/尾三个**真实日期**（`M/D`，节点>3 时才画中间标签，先量宽再决定，不切边不重叠）；Y 轴三条刻度取**真实最大/中值/最小价格**，不虚构数值。
- **1 点 / 空态**：只有 1 个官方节点时画单点图（真实日期 + 真实价格刻度，图注写「仅 1 轮」）；无序列时才显示「未收录 / 暂不可用」占位块。

## 历史从哪来（BesFuel 研究结论）

`m.qiyoujiage.com` 本身**只有当前价和最近一次调价文案**（`tishi`），`/tz/YYYY.shtml` 只有调价日期表，`/fujian/lishi.shtml` 等历史地址均 404（`curl` 实测）。所以原来「装着等两轮」的走势对新用户一直是空白。

用户指定的 <https://github.com/BensonLaur/BesFuel> 正好解决了这个问题：

- 仓库 `lib/history.js` 从 `data/prices.json` 的 `regions[].grades[].history` 生成阶梯图，节点是**各地发改委公告里逐期核对的「价格执行日期 + 元/升」**，`historyGaps` 记录缺表日期并断线，`latestNotice.kind === "unchanged"` 生成空心的「不作调整」观察节点；`checkedAt` 是核对日期。
- `data/prices.json` 由 GitHub Actions 每天北京时间 10:00 / 20:00 抓取广东等 45 个价区更新（<https://raw.githubusercontent.com/BensonLaur/BesFuel/main/data/prices.json>，实测 HTTP 200、约 415 KB；jsDelivr 与 GitHub Pages 副本同样 200）。**只读公开数据文件，不需要账号、API key、签名或 Cookie**。
- 该文件也给 `nationalAdjustment.nextAdjustment.date`（按 10 个工作日 + 放假安排推算的下轮窗口，官方规则），本组件优先采用它，取不到才退回本地按 10 个工作日推算。

许可与再利用边界（已核对仓库 `LICENSE`、`docs/RIGHTS.md`）：

- BesFuel 自写代码与文档是 **MIT License（Copyright (c) 2026 BensonLaur）**，本组件只借鉴其**图表语义**（阶梯线 / 节点 / 不调整空心点 / 缺口断线）并注明来源，没有复制其代码。
- `data/prices.json` 里的价格、执行日期属于**政府公告事实**，`docs/RIGHTS.md` 明确说明这些第三方数据**不随 MIT 许可转移**。因此本组件只展示事实字段（日期、元/升、价区名、核对日期）并标注来源，不复制公告正文/图片，也不把快照称为官方实时服务。若要再发布该数据，应另行核对原公告站点条件。

## 走势的真实含义（与 BesFuel 对齐）

| 显示项 | 来源与语义 |
| --- | --- |
| 相邻节点的直线 | 两次**真实调价**之间的价差趋势（普通折线，不是逐日价格、不是拟合曲线，也不插值） |
| 每个节点 | 一次已核实的官方调价，横轴为价格执行/公告日期（`M/D`）；超过 10 个只画最近 10 个 |
| 绿色大末点 | 最新一次调价（强调用，不附价格标签，避免遮挡） |
| 空心节点 | 官方「本轮不作调整」公告；价格沿用上期，不计入涨跌 |
| 断线处 | 官方公告缺该油号完整价表（`historyGaps`），不把缺失期画成「价格不变」 |
| 最新价与「↑0.08 / ↓0.52」 | 最新官方核价与**上一个不同价格**之差，单位元/升；「官方不调整」显示为 → |
| 图注价区名 | 大号图下**一行精简图注**：`95号 官方核价 · 价区全名 · M/D 生效 · 最新 8.89 · ↓0.55`（如「陕西·西安市区」「贵州第一价区」），**不把 A 价区数据标成 B 价区**；来源域名、核对日期、节点数等明细只写在本 README，不占图表空间 |
| 未收录地区 | 明确显示「BesFuel 未收录该地区」，只显示现价，不出曲线 |
| 98 号 | BesFuel 未逐期核价 98 号（数据中为 null），显示「未收录 98 号官方核价」，不拿 95 号推算 |
| 历史源失败 | 有缓存 → 继续画并标「缓存」；无缓存 → 明说「官方核价历史暂不可用」，现价照常显示 |

现价卡与「最近调价（全国）」仍来自汽油价格网（全国幅度文本），与 BesFuel 的**地区官方核价**是两个口径，界面上分别署名，不混为一个数字。

## 下轮调价信息怎么显示（数据来源与真实限制）

调价信息遵循「能显示下轮就显示下轮，但不能把只有日期的窗口说成下轮涨跌幅」。三个来源的真实字段：

| 来源 | 字段 | 内容 | 能否给「下轮幅度」 |
| --- | --- | --- | --- |
| BesFuel `data/prices.json` | `nationalAdjustment.nextAdjustment`（`date` / `dateLabel` / `sourceName` / `sourceUrl`） | 按「10 个工作日 + 国务院放假安排」推算的下轮窗口，`dateLabel` 自带「预计」 | ❌ 只有日期，没有金额 |
| 同上 | `nationalAdjustment.forecast`（`direction` / `amountPerLiter` / `description` / `sourceName` / `updatedAt` / `windowDate`） | 预留的下轮幅度字段；实测 2026-11-14 快照**全部为 null** | ⭕ 有值时才用（本版本已实现解析与展示） |
| 汽油价格网 `m.qiyoujiage.com` | 页面 `tishi` 文本 | 最近一次调价的方向与幅度（元/升或元/吨） | ❌ 只有上一轮，没有下一轮，也没有原油变化率 |

组件据此分三级显示，界面文案与颜色都有区别：

| 级别 | 触发条件 | 主信息 | 下轮信息 | 标注 |
| --- | --- | --- | --- | --- |
| 预测（有真实幅度） | `forecast.direction` 有效、`amountPerLiter > 0`、`windowDate` 为未来 | **下轮预测（全国）** + `↓0.18`（元/升） | 中号第二块改为最近调价；大号副行写「最近 ↓0.51」 | 文案自带「预测」，颜色按涨跌 |
| 仅窗口（当前默认） | 只有未来日期：BesFuel `nextAdjustment`（规则推算）或本地 10 个工作日推算 | **最近调价（全国）** + 幅度 | 只写日期 + 「预计」/「仅日期 · N 天」，**不配任何幅度** | 「预计」字样 + 「仅日期」 |
| 窗口已过 / 无数据 | 快照日期早于今天，或没有日期 | 最近调价 | 「窗口待更新」/「暂无窗口」 | 绝不把过去日期当下一轮 |

如果 `nextAdjustment` 的 `sourceName`/`dateLabel` 明确是公告（不含「预计/推算/规则/放假」字样），下轮会标成「公告」级：显示公告日期，但仍**不用它配幅度**，主信息仍是最近调价。

**结论（如实说明）**：截至 v4.3.0，两个数据源都没有可信的下一轮涨跌幅度，所以默认走「仅窗口」级——主信息是最近调价，下轮只出现日期并明确标注预计/仅日期。本组件不伪造预测，也不新增未授权数据源；一旦 BesFuel 的 `forecast` 字段被填充，界面会自动升级为「下轮预测 + 幅度 + 预测标注」，无需改脚本。

`region` 先按原有规则解析成省份或省份/城市，再映射到 BesFuel 价区：广东→`guangdong`、福建→`fujian`、海南→`hainan`、北京→`beijing`、陕西/西安→`shaanxi-xian`、云南/昆明→`yunnan-kunming`、西藏/拉萨→`xizang-lhasa`、新疆/克拉玛依→`xinjiang-karamay-main`、内蒙古/呼和浩特→`inner-mongolia-west` 等；省份下有多个价区时取该省主价区并在图注写明完整价区名。`FUEL` 的 92/95/98/柴油分别对应 BesFuel 的 `92/95/98/diesel`。

| 项 | 值 |
| --- | --- |
| 历史源顺序 | `raw.githubusercontent.com` → `gcore.jsdelivr.net` → `bensonlaur.github.io`（三个均实测 HTTP 200） |
| 单请求超时 / 总预算 | 6 s / 13 s（模块脚本 timeout 20 s） |

## 常见问题

**显示「获取失败」**：现价源网络问题或站点不可用；脚本保留上次成功数据（大号底部标「缓存数据」）。历史源独立请求，现价失败时历史仍可能正常。

**显示「BesFuel 未收录该地区」**：该价区还没被 BesFuel 逐期核价（如湖北、甘肃、辽宁目前未导入），或该省只核了部分价区。组件不借用邻近地区数据。

**显示「官方核价历史暂不可用」**：三个历史镜像都失败且本机没有缓存。现价照常显示，下次刷新自动重试。

**历史和加油站价格对不上**：历史是各地**最高零售价**公告值，现价卡是汽油价格网的参考价，二者都可能与某座加油站的挂牌价不同。

**图表不更新**：数据每天 10:00 / 20:00 更新，缓存 6 小时；`refreshAfter` 只是给系统的建议，WidgetKit 实际调度由 iOS 决定。

**图上只有 10 个点**：历史有 20+ 轮，但按参考图只画最近 10 轮真实节点（`slice(-10)`），坐标轴日期/价格都取自真实数据；缺口处会断线，所以段数可能少于 10。
